# Public data dictionary

| Field | Meaning |
|---|---|
| `kaizen_id` | Synthetic stable identifier |
| `title` | Invented improvement title |
| `owner` | Invented responsible person |
| `status` | Synthetic registry status |
| `source` | `local`, `fallback`, or `missing` |
| `category` | Synthetic improvement category |
| `completion_date` | ISO date from the demo input |
| `business_validated` | Explicit business approval flag |
| `publishable` | True only when valid and approved |
| `pending_reason` | Safe, non-sensitive reason for exclusion |
