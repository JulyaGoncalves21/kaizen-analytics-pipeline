# Security policy

## Scope

This repository is a local-only demonstration with synthetic records. It must not receive, process or connect to real corporate improvement data.

## Prohibited content

- Employee, customer, initiative, financial or performance data from a real environment
- Internal classifications, URLs, endpoints, server names, network paths or source schemas
- Original workbooks, reports, dashboards, screenshots, PBIX/PBIT files or governance documents
- Corporate code or connectors, credentials, tokens, cookies, certificates, executables or `.env` files
- Outputs, logs, browser state or backups copied from a private environment

## Reporting

Use GitHub's private security-advisory flow to report accidental exposure. Do not post the sensitive value in a public issue.

## Supported version

Only the current default branch is maintained. This demonstration is not a production data pipeline.
