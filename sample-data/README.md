# Synthetic sample data

All names, identifiers, titles, categories and dates in this directory are invented. The registry models the corporate improvement list; `individual/` models files stored by owner, and `remote-fallback/` demonstrates attachment fallback. `business_validations.csv` is the explicit publication gate.

The private solution reads richer Excel templates and corporate sources. This public dataset deliberately reduces those structures to transparent CSV files and contains no real indicators, costs, URLs or internal text.

Run `python -m kaizen_pipeline.cli --show-summary` from the repository root after installing the project. Generated files are written to `output/` and ignored by Git.
