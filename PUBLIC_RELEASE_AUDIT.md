# Public release audit

## Included

- New local-only Python demonstration derived from the verified workflow boundaries.
- Six synthetic registry records and five synthetic source files.
- Tests for source priority, fallback and pure validation rules.
- Architecture, Power BI boundary and static case-study documentation.

## Excluded

- Every original workbook, CSV, log, output, cache, backup and screenshot.
- All executables and packaging artifacts.
- Corporate endpoints, list names, attachments, browser profiles and credentials.
- Original HTML, PBIX/PBIT content and Power BI metadata.

## Replacements and controls

- People, identifiers, titles, categories and dates are invented.
- External configuration is represented only by blank/generic values in `.env.example`.
- The executable demo has no network or corporate write capability.
- A pre-commit content scan and a Git-history scan are required before publication.

## Limitations

This repository demonstrates the orchestration and validation boundary, not the proprietary Excel parsing, corporate authentication or production report. No claim is made that the synthetic output reproduces operational metrics.

No open-source license is granted in this release because ownership clearance for corporate-derived source material has not been established. The new demonstration remains available for portfolio review under repository copyright terms.
